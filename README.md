# Saya no Uta — Android Port Project
This repository provides a community-compiled Android APK for the visual novel *Saya no Uta*. By utilizing the VNSdroid engine, we have created a stable, native-feeling mobile experience for this title.

## 🚀 Getting Started

Follow these steps to get the game running on your Android device:

* **Download:** Grab the latest `.apk` file from the Releases section.
* **Permissions:** Navigate to your Android Settings and ensure "Install from Unknown Sources" is toggled ON for your browser or file manager.
* **Installation:** Locate the downloaded file and tap to execute the installation process.
* **Launch:** Open the app icon from your home screen. The engine will initialize the asset cache on the first boot.

## 🛠 Troubleshooting

If the application encounters a black screen or fails to load assets, please perform the following checks:

* Ensure you have granted the application **Storage Permissions** via your device's App Info settings.
* Check that your device has at least 1GB of free space to allow for engine decompression.
* If you are on Android 12 or higher, ensure you are not running in a sandboxed "Work Profile" that restricts secondary file access.

## ⚙️ Technical Details

This port is built using the open-source **VNSdroid** interpreter. We do not modify the core game assets; we simply package the engine and script data into a unified, installable Android package.

For those interested in the engine source code, you can visit the official repository: [VNSdroid GitHub](https://github.com/stella684/VNSdroid/releases)
